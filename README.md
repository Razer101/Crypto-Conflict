# 🌐 Macro, Crypto & Conflict Snapshot

An advanced interactive data dashboard built as part of a **Coursera Lab** to analyze and visualize the real-world intersections of global macroeconomic trends, cryptocurrency market movements, and geopolitical events.

## 🚀 App Overview
This application provides a visual snapshot of how global events ripple through financial ecosystems. Using D3 geographic mapping, the app tracks and overlays global market sentiment, macroeconomic factors, commodity futures, and digital asset responses simultaneously onto an interactive world map.

## ✨ Key Features
* **Geographic Data Visualization:** Interactive world mapping powered by D3.js to track macro trends and global hotspots.
* **Crypto Market Data:** Real-time digital asset data and pricing integrated via the CoinGecko API.
* **Commodities & Macro Indicators:** Tracks traditional market sentiment using live NYMEX/COMEX Futures.
* **Geopolitical & News Overlay:** Streams global event updates directly through a Google News RSS integration.
* **AI Intelligence:** Powered by the Google Gemini API to analyze incoming streams and contextually correlate global conflicts with sudden market movements.

## 🛠️ Tech Stack
* **Frontend:** React 19, TypeScript, Vite, Tailwind CSS v4, Lucide React
* **Data Visualization:** D3.js (`d3-geo`, `topojson-client`)
* **Backend / API:** Node.js, Express, `tsx`
* **Data Providers:** CoinGecko API, NYMEX/COMEX Futures, Google News RSS
* **AI Intelligence:** Google Gemini API (`@google/genai`)
